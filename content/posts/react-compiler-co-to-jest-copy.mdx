## What is React Compiler?

React Compiler is a tool built by Meta that analyzes your React code at compile time and **automatically adds memoization** where it is needed.

Instead of writing this by hand:

```tsx title="Before"
const expensiveValue = useMemo(() => computeSomething(a, b), [a, b]);

const handleClick = useCallback(() => {
  doSomething(a);
}, [a]);
```

You can write this:

```tsx title="After" {2,4}
const expensiveValue = computeSomething(a, b);

const handleClick = () => {
  doSomething(a);
};
```

And the compiler handles the rest. Yes — this is not a joke.

## How does it work under the hood?

The compiler analyzes the data dependency graph inside a component. It knows exactly which values can change between renders and generates equivalents of `useMemo` and `useCallback` in the compiled code.

One important condition: **your code has to respect React's rules**. That means not mutating state, not calling hooks conditionally, and so on. If the compiler finds code that does not follow those rules, it simply skips it and does not compile that component.

## It is already in Next.js

If you use Next.js 15+ (or our 16.2.6), one field in the config is enough:

```ts title="next.config.ts"
const nextConfig = {
  reactCompiler: true,
};
```

And that is it. No extra packages, no Babel configuration.

## Does this mean I never write memo again?

<Wave>Almost.</Wave>

There are still cases where manual memoization makes sense:

- Very complex calculations where you need precise control
- Referential equality for objects passed to external libraries
- Specific patterns around virtualized lists

But in 95% of cases? The compiler will handle it better than you.

## What about existing code?

Good news: the compiler is additive. If you already have `useMemo` in your code, it will not be removed — the compiler simply adds what is missing. Over time, you can gradually clean up manual memoization.

Code with unnecessary `useMemo` is, at worst, inelegant — <Strike>it will not explode</Strike> — so the migration is low-stress.

## Summary

React Compiler is one of those tools that simply works and does the job for you. Less boilerplate, fewer memoization bugs, cleaner code.

Enabling it in Next.js takes literally one line. There is no reason not to try it.
